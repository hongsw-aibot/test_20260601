# Week 13 실습 프로젝트 계획 — "AI 한줄메모" 배포하기

> Week13 강의(`Week13_배포_개념과실전.pdf`)의 4가지 핵심 개념(서버 · 도메인 · 환경변수 · HTTPS)과
> 5단계 배포 흐름(GitHub → Vercel → 환경변수 → 배포 → URL)을 **한 프로젝트로 모두 체험**하기 위한 실습 설계서입니다.

---

## 1. 학습 목표 (강의 매핑)

| 강의 개념 | 이 프로젝트에서 체험되는 지점 |
|---|---|
| **서버(Server)** | Vercel이 우리 코드를 24시간 띄워주는 것을 직접 확인 |
| **도메인(Domain)** | `https://<프로젝트>.vercel.app` 자동 발급 URL 사용 |
| **환경변수(Env)** | `OPENAI_API_KEY`, `SUPABASE_URL`, `SUPABASE_ANON_KEY` 3종을 Vercel 대시보드에서 주입 |
| **HTTPS / SSL** | Vercel이 Let's Encrypt 인증서를 자동 적용한 https:// 주소로 친구에게 공유 |
| **로컬 vs 배포** | `npm run dev`(localhost:3000) ↔ 배포본(`*.vercel.app`) 두 환경의 차이를 손으로 비교 |
| **자동 재배포** | `git push` 한 번에 자동 재배포되는 것을 직접 확인 |

> 강의 후반의 "자주 나는 에러 3가지"도 이 프로젝트에서 일부러 한 번씩 만나보고, 직접 고쳐보는 것을 목표로 합니다. (아래 6장 참고)

## 2. 만들 프로젝트: "AI 한줄메모"

### 한 줄 설명
> 사용자가 한 줄짜리 메모를 적으면, **AI가 자동으로 요약 한 줄 + 태그 2~3개**를 붙여 DB에 저장하고, 목록으로 보여주는 미니 웹앱.

### 화면 구성 (총 1페이지)
```
┌────────────────────────────────────────────┐
│  AI 한줄메모                                │
│  ────────────────                          │
│  [ 오늘 배운 것을 한 줄로 적어보세요... ] [저장] │
│                                            │
│  📝 최근 메모                                │
│  ─────────────                             │
│  • "오늘 배포 강의 들음"                     │
│      ↳ AI 요약: 배포 학습 회고               │
│      ↳ 태그: #학습 #배포 #회고                │
│                                            │
│  • "Vercel + Supabase 연결 성공"            │
│      ↳ AI 요약: 풀스택 환경 구성 완료         │
│      ↳ 태그: #Vercel #Supabase #환경구성     │
└────────────────────────────────────────────┘
```

### 왜 이 프로젝트인가
- **AI API 호출이 필요 → 환경변수 학습이 "필수"가 됨** (강의에서 가장 강조한 포인트)
- **DB가 필요 → Supabase 환경변수까지 추가 → 환경변수 2종 관리 경험**
- **결과물이 가볍고 시각적이라 친구에게 URL/QR 공유하기 좋음** (강의 마지막 슬라이드의 "AI 만든 앱 자랑하기" 달성)
- **기능이 1페이지로 끝나서 1~2시간 안에 배포까지 도달 가능**
- 이후 확장(인증, 좋아요, 검색)이 자연스러워 다음 주차 학습으로 이어붙이기 좋음

## 3. 기술 스택

| 레이어 | 선택 | 강의 슬라이드 근거 |
|---|---|---|
| 프레임워크 | **Next.js (App Router)** | "Next.js (SSR)" 백엔드 슬롯, Vercel과 가장 매끄러움 |
| 배포 플랫폼 | **Vercel** | 강의 추천 스택 1순위, Next.js 제작사 |
| DB | **Supabase (Postgres)** | 강의 추천 스택 ("Vercel + Supabase") |
| AI API | **OpenAI** *또는* **Anthropic Claude** | 환경변수 학습에 필요한 시크릿 키 보유 |
| 스타일 | **Tailwind CSS** | 1페이지 UI를 빠르게 |
| 버전관리 | **GitHub** | 5단계 흐름의 시작점 |

> 대안: AI API가 부담스러우면 1차 버전은 "요약/태깅을 가짜로 만들어주는 더미 함수"로 시작해도 좋습니다. **배포 흐름 체험이 우선, AI 품질은 그다음**입니다.

## 4. 실습 흐름 (강의 5단계와 1:1 매핑)

```
[Step 0] 로컬에서 동작하는 앱 만들기 (배포의 출발점)
   └─ npm run dev → http://localhost:3000 확인

[Step 1] GitHub에 Push                                   ┐
[Step 2] Vercel에서 Repo 연결                            │
[Step 3] 환경변수 주입 (Vercel Settings → Env Variables) │ ← 강의 PART 2의 5단계
[Step 4] Deploy 버튼 클릭                                │
[Step 5] 발급된 URL을 친구에게 공유                       ┘

[Step 6] 코드를 한 줄 고치고 git push → 자동 재배포 확인
[Step 7] (선택) 에러를 일부러 만들어보고 빌드 로그 읽기
```

각 단계마다 **"무엇이 어디서 벌어지는지"** 를 한 줄씩 적어두는 것을 권장합니다 (예: "Step 3에서 .env.local의 값을 Vercel에 옮겨 적었다 — GitHub에는 절대 올라가지 않는다").

## 5. 산출물 & 성공 기준

실습이 끝났을 때 다음 4가지가 모두 "예"여야 성공입니다.

- [ ] `https://<내프로젝트>.vercel.app` 형태의 **공개 URL**이 발급되었다
- [ ] 그 URL이 **HTTPS(자물쇠 아이콘)** 로 열린다
- [ ] **친구의 핸드폰**에서 메모를 작성·저장·조회가 된다 (= 24시간 떠 있다)
- [ ] 코드 한 줄을 고치고 `git push` 했더니 **1~2분 안에 배포본이 갱신**되었다

추가 권장:
- [ ] `.env.local`이 `.gitignore`에 들어가 있고, GitHub 저장소에 절대 올라가 있지 않다
- [ ] Vercel 환경변수 화면 스크린샷을 1장 캡처해두었다 (학습 회고용)

## 6. 미리 알아둘 트러블슈팅 (강의의 "자주 나는 에러 3가지")

| 증상 | 강의에서 짚은 원인 | 우리 프로젝트에서 만날 형태 | 1차 대응 |
|---|---|---|---|
| **빌드 에러** | TS 에러 / 빠진 패키지 | `next build` 단계에서 타입에러, `package.json` 누락 | Vercel **Build Log**를 위에서부터 읽기 |
| **환경변수 누락** | `.env`만 챙기고 Vercel UI에는 안 넣음 | 배포본에서 "API key undefined" → AI 호출 실패 | Vercel → Settings → Environment Variables 확인 |
| **CORS / API 오류** | Supabase URL 오타, 도메인 화이트리스트 | 메모 저장 시 4xx | Supabase 프로젝트 URL/Anon Key 재확인, 클라이언트/서버 호출 위치 점검 |

> "**AI 도움받기**: 에러 메시지 + .env 설정 + 호출 코드"를 한꺼번에 붙여 물어보면 가장 빨리 풀린다 — 강의의 권장 디버깅 패턴.
